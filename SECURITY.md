# Embedded Working Group Security Policy

Please report all issues to the public issue tracker for the relevant
repository. In exceptional circumstances, such as active exploitation
in the wild of a security vulnerability, please open an issue to discuss
possible options for submitting a private report.

Please note our [AI tool use policy] requires that AI-generated prose not
be used in issues or pull requests; reports generated by AI may be closed
without further notice.

[AI tool use policy]: https://github.com/rust-embedded/wg/blob/master/CODE_OF_CONDUCT.md#ai-tool-use-policy
